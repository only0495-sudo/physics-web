# physics-web｜高中物理課堂演示強化版

目前正式工作版本位於 `physics-web` 根目錄。這一版以老師在課堂投影演示為主要情境，同時支援學生使用橫向手機、橫向平板與電腦操作。

## 從這裡開始

開啟 `index.html`。首頁可依「力學、電磁學、波動學、近代物理」篩選，也可直接搜尋實驗名稱或概念。

## 相對加速度模擬器

開啟 `相對加速度.html`，或從首頁搜尋「相對加速度」。不依賴網路程式庫，可直接以瀏覽器開啟。

- 三個情境：A、B 同時自由落體；上方落球與正下方上拋球；等加速上升／下降電梯中的天花板螺絲脫落。
- 每個情境都可在地面與移動觀察者之間切換。畫面位置、速度／加速度箭頭、表格與速度圖共同使用 `y′ = y − y觀察者`、`v′ = v − v觀察者`、`a′ = a − a觀察者`。
- A、B 同初速時互看靜止；調整 B 初速可比較非零等速。兩球以相遇或首次觸地為終點。螺絲於 1 秒脫落並繼承電梯速度，接觸電梯地板即停止。
- 拋球提供五組指定參數，包括上升中、最高點、下落中相遇，以及接近地面才追上；預設 h₀ = 60 m、v₀ = 20 m/s，B 在約 2.04 秒到最高點、3 秒於 15.9 m 高處被 A 追上。可自訂高度 20–160 m 與初速 10–40 m/s；若先觸地，介面會明確顯示尚未相遇。
- 電梯只提供向上／向下兩個固定情境，加速度大小均為 2 m/s²（小於 g），沒有參數滑桿；車廂近景以兩倍尺度顯示，窄視窗會適配完整運動範圍。螺絲圖示從天花板內側開始，尖端在終點接觸地板；圖示尺寸為示意，表格與箭頭使用解析模型位置。
- 向量使用單一填色輪廓，箭身加粗、箭頭加大，短向量的箭頭隨長度縮小以維持正確方向；文字會避開向量與物體，座標刻度依可用空間選擇。速度箭頭比例尺在同一組條件下固定，切換視角不改變向量比例尺。
- 提供播放／暫停、0.1 秒步進、時間軸、慢速播放、參數控制、圖表追蹤與等時間殘影。切換視角保留目前時刻；修改參數會重設時間；重設保留選定參數。
- 向上為正，採 SI 單位，忽略空氣阻力，g = 9.8 m/s²；物體圖示不按實際尺寸繪製，接觸終點顯示碰前狀態，不計算碰撞衝量。此新頁支援手機直向，橫向沿用課堂展示版面。
- `node verify-relative-acceleration.cjs` 執行解析解、極值、釋放連續性與相對運動數值微分驗證。以本機伺服器提供頁面後，加上 `--browser` 可執行 Playwright 互動檢查；預設網址為 `http://127.0.0.1:8765`，預設使用 Edge。可透過 `SIM_BASE_URL`、`PLAYWRIGHT_CHANNEL` 與 `SIM_SCREENSHOTS` 設定測試環境。

## 本版修改方向

- 34 個模擬頁都經過個別檢查與修改，不只套用共同樣式。
- 預設進入「老師展示」，並預設開啟投影清晰模式。
- 加粗過細的向量與箭頭、放大圖表與畫布文字，並替重要標示加入高對比外框。
- 移除會造成舊版固定版面重疊的整頁放大，改為針對文字、控制項、Canvas 與 SVG 分別增強。
- 對容易只看到動畫、卻看不出結論的頁面加入即時判讀，例如受力方向、能量轉換、頻率升降、繞射強弱與光譜種類。
- 運動中的方向優先使用附著於物體的向量箭頭；快速變動數字只在確實需要量測或可暫停讀值時保留。
- 磁力線方向以「磁鐵外部 N → S」逐頁核對，3D 圓錐箭頭以自身軸向對準曲線切線，避免只旋轉模型外觀卻指錯方向。
- 個別修正標籤靠近邊界時的裁切、文字與箭頭重疊，以及 3D 電流箭頭長度為零等問題。
- 學生探索／老師展示兩種入口仍可互相切換。
- 每個實驗都有學習目標、預測任務、關鍵提問與探究筆記。
- 老師模式提供三步驟展示節奏、頁面觀察重點卡，並可切換全螢幕展示。
- 老師可把多個實驗加入「課堂展示台」，調整順序、切換預測／操作／解釋階段，並匯出教案。
- 首頁提供五條有前後脈絡的主題課程路徑；老師可整組載入展示台，再個別增減實驗。
- 課堂展示支援全班問題投影、討論倒數與畫面手寫註記。
- 頁面載入前即辨識手機、平板與電腦；橫向手機使用 1320px 課堂版面等比例縮小，較小的橫向平板使用 1180px 版面，電腦維持原生尺寸。
- 手機橫向時將教學工具列收在右側窄欄，避免遮住模擬；直向手機／平板只顯示旋轉提示。
- 手機、平板會限制 Canvas 與 WebGL 的渲染像素倍率，兼顧文字清晰度與動畫流暢度。
- 學生可記錄控制變因、觀察證據、物理解釋與理解信心，並在最多十次量測中記錄與該實驗相符的實際控制量與結果；可匯出 CSV 與 Markdown 學習單。
- `compare.html` 可把任意兩個模擬並排，使用預設比較題或自訂配對，記錄公平比較條件與結論。
- `notebook.html` 會集中整理所有探究進度、多次量測、比較探究與筆記；內容只儲存在目前裝置，不會上傳。
- 所有頁面均保留縮放能力，並加入鍵盤焦點與減少動態效果支援。

## 內容合理性與驗證

- 每一個模擬的量測欄位由該頁實際可調整的參數與可觀察結果個別定義，不使用跨實驗的通用假設欄位。
- 「運動函數圖」的紀錄欄位只記錄運動模式、觀察時刻與 x／v／a，不使用無關的角度欄位。
- 執行 `node verify-renew.mjs` 可檢查 34 個模擬、三種載具辨識與橫向縮放、教學資料、課程路徑、本機連結及 JavaScript 語法。

## 快速操作

- `Alt + G`：開啟教學指南
- `Alt + P`：切換課堂展示
- `Alt + C`：切換投影清晰模式
- `Alt + K`：顯示／隱藏本頁觀察重點
- `Alt + R`：重設目前模擬
- `Esc`：關閉教學指南或離開全螢幕

部分 3D 或圖表實驗使用外部程式庫，開啟時需要網路連線。
